    Frequently asked questions: Elements Massage vs Exercise Coach

    Is Elements Massage cheaper than Exercise Coach to start?

    Based on the initial franchise fee disclosed in each franchisor's most recent FDD, Elements Massage has the lower starting fee — about $4,550 less than Exercise Coach. This compares only the franchise fee itself, not the total investment range (which includes build-out, equipment, working capital, and other line items). See the comparison table above for both totals.

    Which has the lower total investment, Elements Massage or Exercise Coach?

    The franchisor-disclosed total investment range is $567,239–$1,097,853 for Elements Massage and $262,735–$481,369 for Exercise Coach. By midpoint, Exercise Coach has the lower investment requirement. Your actual cost depends on location, build-out specifics, and whether you self-finance — see each brand's full Item 7 disclosure for the line-item breakdown.

    What royalty does Elements Massage vs Exercise Coach charge?

    Both charge a 6% royalty on gross sales — identical.

    Which has more locations, Elements Massage or Exercise Coach?

    As of the latest reporting year, Elements Massage reported 239 outlets and Exercise Coach reported 221. Elements Massage is the larger system. Bigger isn't automatically better — it can mean more brand recognition but also a more saturated territory map. Check each brand's outlet-growth chart for the trend over time.

    Do both Elements Massage and Exercise Coach disclose Item 19 earnings?

    Yes — both franchisors include Item 19 Financial Performance Representations in their most recent FDDs. Elements Massage reports 28 cohort × metric records; Exercise Coach reports 39. See each brand's Item 19 table for the full breakdown.
