Methodology

Every figure on this site is extracted from a publicly-filed Franchise Disclosure Document. This page documents how that happens — the source portals we scrape, the prompts we use to extract structured data, the validation discipline we apply, the limitations we know about, and the refresh schedule we follow.

1. Data sources

Franchise Disclosure Documents are filed with state securities regulators in 14 US "registration states." Each state runs its own filing portal with its own UX and download mechanism. We pull from these portals in priority order:

  • Wisconsin DFI Franchise Search (apps.dfi.wi.gov/apps/FranchiseSearch) — currently 1,879 active franchisor registrations. Our primary source today. Stateful ASP.NET form requires browser automation (Playwright) to navigate.
  • Minnesota CARDS (cards.web.commerce.state.mn.us) — modern document portal with direct PDF URLs. Used for cross-state validation and for brands not registered in WI.
  • Planned: California DFPI DOCQNET — largest single state by filing volume. Different UI requires its own scraper module.
  • Planned: Indiana SOS, NASAA EFD — Indiana has a clean modern portal (2019+ filings only); NASAA is a multi-state depository for franchisors that file in several states.

FDDs are public records. Item 19 data is published by the franchisor with full knowledge it will be read by the public; republishing the structured data is not infringement. Where the franchisor's narrative text in the source PDF is copyrighted (the writing, not the data), we summarize methodology in our own words and link back to the source filing rather than reproducing FDD prose verbatim.

2. What we extract

Per FDD, we parse five specific Items from the FTC's required disclosure structure:

ItemWhat it coversOur extracted fields
Item 5Initial franchise feefee low, fee high, fee notes
Item 6Ongoing feesroyalty %, marketing fee %, technology fee monthly, fee notes
Item 7Estimated initial investmenttotal investment low, total investment high, liquid capital required, net worth required
Item 19Financial performance representations (when disclosed; ~66% of FDDs)per-cohort records: metric, cohort name + raw description, outlet count, reporting period, avg, median, min, max, percentile 25, percentile 75, % above average
Item 20Outlet activity (always required)yearly summary by outlet type (franchised, company-owned, total); state-by-state activity: starts, opens, terminations, non-renewals, reacquisitions, ceased other reasons, ends

We don't republish narrative text from the FDD. We extract structured facts only — numbers, table rows, dates. The franchisor's writing remains theirs; the data remains public.

3. How extraction works

  1. Scrape: The Wisconsin scraper (source) uses Playwright + Chromium to navigate the stateful ASP.NET portal. It searches by brand name, filters to currently-Registered filings (skipping Expired), and clicks the per-filing Download button which triggers a server-side POST that returns the PDF.
  2. Hash + dedup: Every downloaded PDF is SHA-256 hashed. The same franchisor often files near-identical FDDs across multiple states; we extract only the first instance and reuse outputs for SHA matches.
  3. Section detection: For each FDD, a Python regex locates the body page ranges for Items 5, 6, 7, 19, and 20 by matching the canonical FTC heading text (e.g., "FINANCIAL PERFORMANCE REPRESENTATIONS"). The regex tolerates several format variations including comma-separated titles ("FINANCIAL PERFORMANCE, REPRESENTATIONS"), unicode dashes rendered as "?" by PDF text extraction, and Table-of-Contents pages that would otherwise produce false matches.
  4. Cover-page detection: A separate scoring heuristic identifies the FDD cover page (where the legal name, state of incorporation, address, and issuance date live). This is distinct from "body start" because the cover usually appears before the legal preamble + state addenda + table of contents.
  5. LLM extraction: The relevant pages for each Item are sent to Anthropic's Claude Sonnet 4.6 with an item-specific structured-output prompt. For Items 19 and 20, we also include rasterized page images at 1.7× scale — Claude's vision capability handles tabular content that doesn't extract cleanly as text.
  6. Structured output validation: The model returns JSON conforming to a per-item schema with a self-rated 0.0-1.0 confidence score. A lenient parser handles common JSON escape issues (unescaped quotes inside strings, trailing commas, multi-line strings without escapes); on the rare unrecoverable parse failure, the raw model output is retained for manual review rather than silently dropped.
  7. Database ingest: JSON outputs are merged into a SQLite database via an idempotent upsert pattern. Brand entities are keyed by slug; FDDs by SHA-256.
  8. Site generation: A Jinja2-based static-site generator renders one HTML page per brand + category aggregation pages + index. Pages include schema.org Article markup with author, dateModified, and FAQPage entries for AI search engine citations.

4. Validation discipline

We've validated the pipeline on four reference FDDs spanning distinct failure modes: a single-cohort case (Crumbl 2023), a no-FPR-disclosed case (Service Experts 2025), a multi-cohort stress test (ReBath 2025), and a scanned-PDF case (Servpro 2014) that exposes the pipeline's current OCR gap. We then ran a 20-brand pilot of home-services franchisors from Wisconsin to test the prompts across the natural variance of real filings.

On every numeric value we've manually spot-checked against the source PDF, the extracted value has matched. The 4-FDD + 20-brand validation surfaced and fixed three real bugs: section regex too strict on dash + comma variations (JDog, Two Men); missing cohort enum value for multi-unit ownership groups (Mr. Handyman, Merry Maids); JSON escape errors silently dropping otherwise-valid extractions (Anago).

Extraction at scale will hit edge cases we haven't seen yet. If you spot a number that's wrong, click the page-number link on the relevant Item 19 row to open the source filing and verify. We'd rather you trust the source than trust us.

5. Refresh schedule

Franchisors are required to file an updated FDD annually if they wish to continue offering franchises in a registration state. Our refresh approach matches that cadence:

  • Quarterly batch refresh: every 3 months, the scraper re-checks every brand currently in our database for a newer Registered filing. If found, the new PDF is downloaded, deduped against the existing version by SHA-256, and re-extracted only if the hash changed. This catches mid-year amendments and renewal filings.
  • New-brand backfill: the scrape loop runs continuously against the WI active-filings list and ingests any brand that has a currently-Registered filing and isn't already in our database.
  • Page-level "last verified" stamps: every brand page displays its source FDD's filing year and issuance date prominently in the header so visitors know exactly how fresh the data is. Stale data is the #1 trust killer in franchise research; we'd rather acknowledge our refresh latency than hide it.

6. Estimated breakeven — how it's calculated

For brands that disclose Item 19, the breakeven estimate combines existing-data inputs in this preference order:

  1. Directly-reported net profit (dollars). If the FDD reports actual net profit per outlet in dollar terms, we use those figures directly.
  2. Directly-reported net income margin percent. If the FDD reports a net income margin (e.g., "Average Net Income 9.8%"), we apply it to the reported revenue.
  3. Industry-typical margin applied to reported revenue. When no profit figure is disclosed, we apply an industry-typical operating margin band to the broadest reported revenue cohort.

Industry-typical operating margin bands we apply when option 3 is needed:

  • Food / QSR: 8–15%
  • Home services (plumbing, HVAC, cleaning, restoration, roofing, painting, handyman, outdoor): 18–30%
  • Senior care, remodeling, moving: 15–25%
  • Real estate brokerage: 10–20%
  • Other / unclassified: 10–20%

The formula is straightforward: investment midpoint divided by estimated annual profit equals years to breakeven. We deliberately prefer broad cohorts (e.g., "all franchised outlets") over performance-anchored quartile cohorts ("Top 10%") for the optimistic side, because applying high margins to the top 10% of outlets produces unrealistically fast breakeven times that don't represent a typical buyer's experience.

This is an arithmetic estimate, not a forecast, not a guarantee. Actual breakeven varies widely by location, owner involvement, financing terms, local market conditions, and operating discipline. If a brand doesn't disclose Item 19, we don't estimate breakeven and we say so plainly.

7. System health badge — how it's calculated

From Item 20's required state-by-state outlet activity table, we compute closure rate as: 

closure_rate = (terminations + non-renewals + ceased-other) / total outlet-years

Buckets are purely arithmetic, with no human judgment in the categorization:

  • 🟢 Stable: closure rate < 3%
  • 🟡 Mixed: closure rate 3–7%
  • 🔴 Contracting: closure rate > 7%

Transfers between franchisees don't count as closures (the outlet continues operating under a new owner). Reacquisitions by the franchisor also don't count. The labels are descriptive of the closure rate, not editorial judgments about the franchise's quality — a "Contracting" badge on a niche brand undergoing a strategic refocus isn't the same as one on a brand losing buyer trust, and we leave that interpretation to the reader plus their conversations with current franchisees.

9. What we don't have (limitations)

  • Scanned PDFs. Some older filings are scanned images rather than born-digital PDFs. Our preflight survey of 19 modern (2024-2025) MN-filed FDDs found zero scanned outliers, but older historical filings (Servpro 2014, for example) are scanned and produce garbled text. An OCR fallback step is on the backlog; modern filings don't need it.
  • Franchisee testimonials, reviews, or ratings. We don't include them. Cannot validate them; would compromise our trust framing. Item 20 of every FDD contains the federally-required list of current and former franchisees with contact information — that's the right place to source firsthand accounts.
  • Editorial rankings. No "Best Franchise 2026" lists. Pure data display, reader decides.
  • Item 21 (financial statements), Items 1-4 narrative, Items 8-18 operational detail. These exist in the source FDD; we don't currently extract them. Item 1 (parent company, history) is on the roadmap; the operational-detail Items are lower priority.
  • Comparison across filing years for the same brand. Today the database reflects the most recent Registered filing per brand. Historical trend pages (year-over-year revenue evolution) require ingesting expired filings, which we don't currently do.
  • Brands not in any registration state. Some franchises operate only in non-registration states. They don't appear in our database because the source material doesn't exist publicly.

11. Glossary

Plain-English definitions of jargon used throughout the site. Linked from tooltips on brand pages and comparison pages.

FDD (Franchise Disclosure Document)
The 23-section legal document every franchisor must file before selling franchises in a registration state. Updated annually. The source for every number on this site.
Item 5 — Initial fees
The one-time franchise license fee paid to the franchisor when you sign. Doesn't include equipment, build-out, or working capital — those are Item 7.
Item 6 — Ongoing fees
Recurring fees: royalty (% of gross sales), marketing/brand fund (% of gross sales), technology fees, transfer fees, etc. Often the difference between a profitable and unprofitable franchise.
Item 7 — Total investment
The franchisor's estimate of total cost to open and operate the franchise for the first 3 months. Includes initial fee + build-out + equipment + working capital. Always given as a range (low to high).
Item 19 — Financial performance representations (FPR)
The section where franchisors disclose actual financial performance of existing outlets. Disclosure is voluntary — many franchisors omit Item 19 entirely. When present, it's the only legally-vetted earnings data buyers can use.
FPR (Financial Performance Representation)
The formal term for the contents of Item 19. Regulated by FTC §436.5(s) — any forecast or projection must come from Item 19; third parties (including this site) can't legally make projections about your specific results.
Item 20 — Outlet activity
The required state-by-state outlet table showing openings, closures, terminations, non-renewals, transfers, and reacquisitions per year. The source for our closure rate calculation.
Royalty
An ongoing percentage of gross sales paid to the franchisor, typically weekly or monthly. Common range: 4-10%. Critical to compare: a 6% vs 10% royalty on $500K annual sales is a $20K/year difference.
Liquid capital requirement
The franchisor's minimum cash-on-hand requirement for prospective franchisees. Usually below the total investment — the rest is expected to come from financing.
Cohort (Item 19)
A subset of outlets the franchisor groups together for reporting (e.g., "outlets open 1+ years", "Top 25%", "company-owned"). Different cohorts can produce wildly different earnings figures — always check which cohort a number describes.
Cohort types we tag
We classify cohorts into all_franchised, all_company_owned, open_X_plus_mo (tenure-based), performance_anchored (Top X%), ownership_group_anchored, and tenure_year_anchored. See section 8 (data dictionary) for the full schema.
Closure rate
(terminations + non-renewals + ceased-other) ÷ total outlet-years across the disclosed reporting years. Transfers and reacquisitions are NOT counted — the outlet continues to operate. Banded green < 3%, yellow 3-7%, red > 7%, purely arithmetic.
Arithmetic breakeven scenario
Total investment midpoint ÷ estimated annual profit. We pick the profit figure in this preference order: franchisor-reported net profit dollars → franchisor-reported net margin % → industry-typical margin. This is not a projection. Per FTC §436.5(s), only the franchisor's Item 19 disclosure is an authoritative source.
