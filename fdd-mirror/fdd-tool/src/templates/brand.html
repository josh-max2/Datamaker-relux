Under the scenario described below, breakeven would arrive in {{ breakeven.low_years }}{% if breakeven.high_years %} – {{ breakeven.high_years }}{% endif %} years.

It is an arithmetic exercise on data the franchisor already disclosed in this {{ latest_fdd.filing_year }} FDD: investment midpoint of ${{ '{:,.0f}'.format(breakeven.investment_midpoint) }} divided by estimated annual profit. {% if breakeven.method == 'reported_net_profit_dollars' %} The profit figure used is the franchisor's directly-reported net profit from Item 19 across {{ breakeven.n_cohorts }} cohort{% if breakeven.n_cohorts != 1 %}s{% endif %}. {% elif breakeven.method == 'reported_net_margin_pct' %} The profit figure used is the franchisor's directly-reported net income margin ({{ breakeven.margin_low_pct }}–{{ breakeven.margin_high_pct }}%) applied to their reported revenue. {% else %} The franchisor does not disclose a net-profit figure, so this scenario applies an industry-typical operating margin band of {{ breakeven.margin_low_pct }}–{{ breakeven.margin_high_pct }}% (for {{ breakeven.industry_label.lower() }}) to their reported revenue — a rougher inference, not a measurement. {% endif %} Per FTC §436.5(s), the franchisor's own Item 19 disclosure is the authoritative source for any forecast — this scenario is illustrative arithmetic only, with no claim about what any individual buyer will experience.
